# DiskGuardian — Security Model

> 版本 0.7.0

## 1. 威胁模型

| 威胁 | 假设 | 对策 |
|---|---|---|
| 模型被诱导执行危险操作 | 提示词注入、错误推理 | 引擎独立判定 L 级；工具不接受模型给的风险/批准；无任意命令工具 |
| 模型伪造"用户已同意" | 模型输出 `approved: true` | 该字段不存在于任何执行路径；批准只能由引擎在真实用户确认后签发 |
| 批准被重放 | 重复调用 | 一次性记录，执行开始即原子消费；用于修改目标后再执行 → 哈希不匹配 |
| TOCTOU（批准后替换文件） | 目标在预览后被替换 | 执行前重算 `(size, mtime_ns, inode)`；任一漂移整批拒绝 |
| 路径穿越 / 符号链接 | 临时目录内的重解析点 | 拒绝重解析点及其祖先链、硬链接、目录、UNC、非固定磁盘 |
| 恶意卸载命令 | 注册表被写入 `cmd /c ...` | 卸载器白名单校验：拒绝解释器、临时/下载目录；MSI 必须带 `/X` |
| 提权 | 引擎以当前用户运行 | 从不调用 UAC/提权；`740` → `E_ELEVATION_REQUIRED` |
| 数据外泄 | 插件/引擎联网 | 引擎不发网络请求；只读白名单字段；浏览器敏感文件在代码中不存在 |

**明确的非目标**：DiskGuardian 不是反病毒产品。它不判定恶意软件、不隔离威胁、不替代 Defender。

## 2. 权限等级

| 级别 | 定义 | 实现 |
|---|---|---|
| L0 | 只读检查 | 9 个扫描器 + 分析器；不需要确认 |
| L1 | 严格条件下的临时/缓存清理 | 规则全满足才 eligible；**本版仍要求一次确认** |
| L2 | 中风险（回收站等） | 仅识别，不进入计划；提示用户用 Windows 处理 |
| L3 | 高风险（卸载、启动项、系统服务） | 卸载/启动项逐项确认 + 一次性批准；系统服务不提供工具 |
| L4 | 禁止 | 个人文档、Windows/Program Files、未知路径、网络路径、重解析点、系统启动项 → 不可加入计划 |

## 3. 授权不变量

1. 计划创建不产生副作用。
2. 只有用户通过 Harness 确认 UI 的明确选择才触发 `issue_approval`。
3. 批准绑定 `plan_hash` + 目标清单哈希 + TTL（15 分钟）+ 一次性。
4. 执行前重新验证：批准未用、未过期、计划未变、目标未变。
5. 消费批准后才执行；执行失败不回滚批准（宁可浪费一次授权）。
6. 所有副作用操作写 `action_logs`，含成功与失败。

## 4. 数据最小化

- 只保存扫描摘要、计划、批准、审计、隔离记录、启动项原始值。
- **不保存**密码、Cookie、自动填充、浏览历史、登录凭据；数据库没有对应表。
- 浏览器只读：`Local State`、`Preferences`、扩展 `manifest.json` 的白名单字段。
- 存储位置：`%LOCALAPPDATA%\DiskGuardian\`（当前用户）。

## 4.1 隔离区边界

- 容量上限：默认 5 GiB（`QUARANTINE_MAX_BYTES`）。计划总量超出剩余容量时整份拒绝（`E_QUARANTINE_FULL`），且**不消费批准**，释放空间后可用同一批准重试。
- 保留期限：默认 30 天。`list_quarantine` 返回每条记录的 `expires_at` 与 `expired`。
- **不自动删除**过期隔离项：清理隔离区是永久删除，必须由用户自己做；DiskGuardian 只报告。
- `purge_quarantine`（0.9.0 起）允许用户显式永久删除：先 dry-run 预览，再经确认卡片，仅删除
  仍在 `quarantined`、路径位于隔离目录内、且 SHA-256 与记录一致的副本；任何不符则拒删并审计。
  这是唯一不可恢复的路径，且必须由工具内的用户确认触发。
- 隔离区与源文件同卷（`%LOCALAPPDATA%`）——移入隔离**不会**释放磁盘空间，只有 purge 后才会。
- 隔离目录与数据库同属当前用户；不承诺跨用户或跨机器可恢复。

## 5. 残余风险（如实列出）

1. **插件代码在 Host 进程内运行**，与所有已安装插件同一信任级。安装前需审查源码。
2. **引擎以当前用户身份访问文件系统**，不受 Harness 文件沙箱约束；路径边界由引擎自己维护。
3. **一次性批准 + 消费即失效**：执行中途失败不会自动退回批准，用户需重新确认。
4. **卸载不可回滚**：调用厂商卸载器，DiskGuardian 无法恢复已卸载软件。
5. **浏览器配置变更未实现**，因此不存在"改坏配置"的风险，但用户需自行处理扩展。
6. **Windows 10 未实测**：代码用能力检测，但不能据此宣称已验证。
7. 本版**没有**代码签名与发布渠道校验；以本地目录安装，信任来自用户对源码的审查。

## 6. 安全测试覆盖
